🚀 COMO INICIAR O SISTEMA
═══════════════════════════════════════════════════════════

TERMINAL 1 - BACKEND
───────────────────────────────────────────────────────
$ cd backend
$ venv\Scripts\activate
$ python main.py

Esperado:
  🚀 Iniciando servidor em http://localhost:5000
  📊 Dashboard: http://localhost:8080

Testes:
  • http://localhost:5000/health → {"status": "ok"}
  • POST /api/auth/login
  • GET /api/price-changes (com token)

TERMINAL 2 - FRONTEND
───────────────────────────────────────────────────────
$ cd frontend
$ python -m http.server 8080

Esperado:
  Serving HTTP on 0.0.0.0 port 8080

NAVEGADOR
───────────────────────────────────────────────────────
1. Abrir http://localhost:8080
2. Ver sidebar + modal de login
3. Fazer login com:
   Email: admin@pricetracker.com
   Senha: admin123
4. Dashboard com 3 alterações de preço
